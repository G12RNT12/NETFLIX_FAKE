# 🎬 NETFLIX_FAKE

Proyecto frontend inspirado en la interfaz de Netflix, desarrollado como práctica de desarrollo web utilizando **React, TypeScript y Tailwind CSS**.

El objetivo del proyecto es recrear la experiencia visual de una plataforma de streaming, trabajando componentes reutilizables, diseño responsive e interfaces modernas.

> Este proyecto fue desarrollado únicamente con fines educativos y de portafolio. No está afiliado oficialmente con Netflix.

## 🚀 Demo

Puedes ejecutar el proyecto localmente siguiendo los pasos de instalación indicados más abajo.

## ✨ Características

- Interfaz inspirada en una plataforma de streaming.
- Hero principal con contenido destacado.
- Navbar de navegación.
- Secciones de películas y series.
- Tarjetas de contenido reutilizables.
- Carruseles horizontales.
- Diseño responsive para desktop, tablet y móvil.
- Estilos desarrollados con Tailwind CSS.
- Componentes desarrollados con React y TypeScript.

## 💻 Instalación

Clona el repositorio:

```bash
git clone <URL-DEL-REPOSITORIO>
```

Ingresa al proyecto:

```bash
cd NETFLIX_FAKE
```

Instala las dependencias:

```bash
npm install
```

Ejecuta el proyecto:

```bash
npm run dev
```

Luego abre en tu navegador la dirección local indicada en la terminal.
